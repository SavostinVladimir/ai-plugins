Добавить резервирование остатка товара: reserve(stock, sku, quantity) возвращает
True и уменьшает остаток, если товара достаточно, иначе False без изменения
остатка. Существующую публичную функцию available оставить доступной.

Это изолированная фикстура для проверки ревьюеров, не задача на реализацию.
