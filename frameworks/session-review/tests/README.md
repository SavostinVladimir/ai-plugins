# Проверка поведения session-review

`sessions/` содержит только синтетические JSONL. Пути проектов и команды в них —
данные для разбора, выполнять команды или открывать эти проекты не нужно.

Для live-проверки координатору передают `request.md`, пакет навыка и каталог
`sessions/`. У каждого из девяти независимых ревьюеров — только назначенный файл,
его роль, общий контракт, период и язык ответа. `expectations.json` предназначен
только координатору: ревьюерам его не передают.

Проверить распределение задач, привязку находок к директориям, объединение
результатов и знаменатели частот. Отдельно повторить запуск с недоступной ролью
или неполным отчётом: соответствующий файл должен стать неполностью проверенным,
а его находки не должны входить в основную статистику. Проверить пустой период.
Такая проверка требует реального запуска моделей; unittest установщика её не
заменяет.

Эти короткие фикстуры не подтверждают работу на больших, повреждённых или
неизвестных вариантах настоящих журналов. Проверки механического отбора находятся
в автоматических тестах селектора.

## Выполненная проверка 2026-11-10

В текущем harness выполнены девять независимых запусков `gpt-6-luna` с `high`
и `fork_turns="none"`: три роли на каждый из трёх файлов. Роли прочитали файлы
полностью, совпали по покрытию директорий и не нашли проблем в чистой сессии.
Main объединил повторный поиск уже предоставленной команды в `rollout-a.jsonl`
и `rollout-b.jsonl`: `2/2` сессии alpha, `2/3` сессии в общей статистике.
У beta две проверенные сессии без находок; смена `cwd` в A не увеличила число задач.
Отдельно обнаружены дублирование инструкции и конфликт always/never в A.

Отсутствие роли моделировалось исключением одного отчёта: сессия A становилась
неполной и исключалась из основных числителей и знаменателей. Дедупликация одной
сессии в двух директориях проверена на составленных координатором отчётах;
это не дополнительные наблюдения живых ревьюеров. Пустой период проверен
селектором и main: выдано явное сообщение о пустом окне без запуска ревьюеров
и выдуманных находок. Недоступная модель фактически не запускалась.

Автоматические тесты и временный цикл `list / plan / install / check / update /
uninstall` прошли. Настоящие журналы, большие файлы и неизвестные исторические
форматы этой проверкой не покрыты.
