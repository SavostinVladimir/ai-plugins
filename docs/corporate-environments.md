# Корпоративные harness и sandbox

Установщик пишет только по путям, видимым **процессу, который его запускает**.
Путь хостовой машины не обязательно доступен внутри контейнера. Запускайте менеджер
в нужной среде либо передавайте реальные смонтированные каталоги.

`--config` указывает наш файл экземпляров, `--config-path` — путь нативного конфига
клиента для отображения и привязки state. Нативный конфиг не переписывается.

Приоритет путей: CLI → выбранный экземпляр → документированные client hints → defaults.
Для Codex используется CODEX_HOME; инструкции по умолчанию направляются в
AGENTS.override.md, если он существует, иначе AGENTS.md. Явный instructions-path
всегда имеет приоритет: убедитесь, что корпоративный harness читает именно его.
Skills по умолчанию устанавливаются в ~/.agents/skills независимо от CODEX_HOME.

Неизвестный экземпляр, нераскрытая переменная окружения, конечный файл-ссылка,
коллизия пути и чужой registry приводят к ошибке. Ссылки на родительские каталоги
разрешаются и отображаются как реальные пути. Разные окружения должны использовать
разные state-path. Registry привязан к фиксированному Codex-формату, имени экземпляра и всем путям.

```bash
python3 manage.py plan spec-review --config /mounted/instances.toml --instance corporate-codex
```

Plan не проверяет аккаунт, сеть или поддержку возможностей моделью и не создаёт
файлов. Install сообщает реальные ошибки прав. Read-only mount не заменяется
домашним каталогом, обход sandbox не выполняется. Установщик сохраняет настройки,
но не заставляет внешнюю корпоративную обёртку обнаруживать произвольные пути.
После установки проверьте в клиенте наличие навыка и пяти ролей, выбранную модель
и независимый запуск. Отсутствующие возможности означают неполную интеграцию.

## Один общий путь

`plan spec-review --codex-home /mounted/codex` и `install spec-review --codex-home /mounted/codex` помещают все компоненты под этот корень: agents/, skills/, AGENTS.md (либо существующий AGENTS.override.md), config.toml (без записи), .agent-frameworks/state/<instance>. Повторяйте --codex-home для остальных lifecycle-команд. Отдельные component flags и instance.paths приоритетнее. Без флага прежние defaults, включая ~/.agents/skills, сохранены. Корпоративный harness должен обнаруживать выбранную папку; флаг установщика не меняет его sandbox или правила загрузки.
