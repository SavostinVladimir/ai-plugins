For a requested code review, use {{invocation}} to run six independent reviewers: concurrency and state integrity, test quality, architecture and unnecessary complexity, project code style, critical OWASP security vulnerabilities, and implementation fidelity to the specification. Run them concurrently within session limits on their configured Luna models, each with fresh history and only role-relevant inputs. Follow the installed skill's dispatch and synthesis workflow; do not substitute the author's own review.

Standalone review does not authorize code changes. Missing project style rules require the style reviewer to ask the parent for a separate subagent to document verified conventions in AGENTS.md; the reviewer must not invent conventions or edit files itself. Missing specifications, unavailable models, or missing history-free spawning must be reported as incomplete affected checks. Explicit user instructions may skip or change the workflow.
